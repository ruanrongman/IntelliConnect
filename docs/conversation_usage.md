# 会话模型用量统计

Router 在每轮请求中创建独立累加器，并在返回或异常退出时保存一次用量快照。普通文字、文字流式、小智语音、音频上传、微信文字及微信语音共用此入口。文字流式保留外层累加器发送 SSE `usage` 事件，保存由 Router 统一负责，避免重复计入。

微信图片识别直接调用视觉模型，在该入口单独收集和保存用量。微信统计按解析得到的产品归属，使用与 Router 聊天历史相同的 `appid + openid` 会话 ID。小智使用已有的设备会话 ID，音频上传使用已有的产品会话 ID。

通过 `/api/v2/llm/usage/conversation?productId=...&chatId=...` 查询累计统计；`ai.usage.enabled` 和 `ai.usage.persist` 控制是否统计、保存。服务商未返回 usage 的调用仅增加调用次数及本地估算，不伪造真实 Token。没有模型调用的轮次不保存。

统计覆盖 LLM 调用，不包含 ASR/TTS 费用。每轮保存的是 Router 退出时的快照，之后才完成的后台摘要、情感及图谱任务仍只写诊断日志。此次补齐对新增调用生效，无法补算之前未保存的轮次。
